# بوابة دفع اتصالات كاش (Etisalat Cash Payment Gateway)

تطبيق أندرويد يعمل في الخلفية على موبايل التاجر، يراقب رسائل الـ SMS التأكيدية
الواردة من **اتصالات كاش**، ويستخرج منها تلقائياً:

- 💰 المبلغ
- 📱 رقم موبايل المرسل
- 🔢 رقم العملية / المرجع

ثم:
1. يعرض إشعاراً فورياً بكل دفعة مستلمة.
2. يسجل آخر 200 عملية داخل التطبيق.
3. (اختياري) يرسل كل عملية كـ JSON `POST` إلى رابط Webhook من اختيارك
   (مثلاً نظام المحاسبة أو موقع المتجر).

## طلب الدفع (v1.1)

من زرار **«💸 إنشاء طلب دفع لأي محفظة»**:

1. أدخل رقم محفظتك (مرة واحدة، يُحفظ تلقائياً)، رقم محفظة العميل، والمبلغ.
2. اضغط **إرسال طلب الدفع SMS** — تصل للعميل رسالة فيها رقم محفظتك والمبلغ
   ورقم الطلب وطريقة التحويل (`*777#` أو تطبيق اتصالات كاش).
   أو اضغط **مشاركة** لإرسالها عبر واتساب أو أي تطبيق آخر.
3. عند تحويل العميل، يطابق التطبيق الدفعة الواردة مع الطلب تلقائياً
   (نفس الرقم + نفس المبلغ)، ويعلّمه **✅ مدفوع**، ويصلك إشعار
   «تم سداد طلب الدفع R…»، ويُضاف `matchedRequestId` في رسالة الـ Webhook
   لمطابقة الطلبات في نظامك.

> ملاحظة: اتصالات كاش لا توفر API عام لإنشاء «لينك دفع» حقيقي، فالطلب يُرسل
> كرسالة تعليمات، والتأكيد يتم آلياً عبر مطابقة رسالة التحويل الواردة.

## ملف التثبيت

`EtisalatCashGateway-v1.1.apk` — موقّع بمفتاح debug (مناسب للتثبيت اليدوي).

## التثبيت على Oppo F11 (ColorOS)

1. انقل ملف الـ APK للموبايل وثبّته
   (فعّل «التثبيت من مصادر غير معروفة» عند الطلب).
2. افتح التطبيق واضغط بالترتيب:
   - **١. منح الأذونات** — وافق على رسائل SMS والإشعارات.
   - **٢. تشغيل خدمة المراقبة** — سيظهر إشعار دائم «بوابة اتصالات كاش شغالة».
   - **٣. استثناء من توفير البطارية** — اختر «السماح / عدم التحسين».
3. خطوات إضافية مهمة في ColorOS حتى لا يوقف النظام التطبيق:
   - الإعدادات ← إدارة التطبيقات ← بوابة اتصالات كاش ← فعّل **التشغيل التلقائي (Auto-launch)**.
   - من شاشة «التطبيقات الأخيرة» اسحب التطبيق للأسفل واضغط 🔒 **قفل** لمنع إغلاقه.

## الخصوصية والأمان

- التطبيق يعالج فقط رسائل الوارد من مرسل «Etisalat» التي تحتوي على
  كلمات استلام مبلغ — رسائل OTP والرسائل الصادرة يتم تجاهلها.
- لا يتم إرسال أي بيانات للخارج إلا لرابط الـ Webhook الذي تدخله أنت بنفسك.
- لا يقرأ التطبيق محتوى تطبيق اتصالات كاش نفسه ولا يتحكم فيه.

## البناء من المصدر


## هيكل المشروع

| الملف | الوظيفة |
|---|---|
| `SmsReceiver.java` | استقبال رسائل SMS من النظام حتى والتطبيق مغلق + مطابقة الطلبات |
| `SmsParser.java` | استخراج المبلغ/المرسل/المرجع (عربي + إنجليزي + أرقام هندية ٠١٢٣) |
| `PaymentRequestActivity.java` | شاشة إنشاء طلب دفع وإرساله SMS أو مشاركته |
| `PaymentRequest.java` / `RequestStore.java` | نموذج طلب الدفع وتخزينه ومطابقته مع الدفعات |
| `GatewayService.java` | خدمة أمامية دائمة + إعادة التشغيل بعد إعادة تشغيل الموبايل |
| `TransactionStore.java` | حفظ العمليات محلياً + إعدادات الـ Webhook |
| `WebhookSender.java` | إرسال JSON لكل عملية إلى رابطك |
